# P04-T 数学复核与结项说明

日期：2026-09-13。范围仅为既有证据的只读复核与纯 CPU 代数检查；不构成新诊断、算法或训练包。**接受 P04-T 执行有效及 `INCONCLUSIVE_STOP`：当前固定 OAC 路线结项，不进入原 P05，不追加 P04、Room、seed 或 30k；原 GS-RU 和全部模型、快照、数据、结果保持不变。**“停止推进”不等于证明所有 OAC 变体无效。

## 已验证事实

- 既有 [P04-T 报告](REPORT_P04T.md)、[汇总数据](analysis.json)与[逐对象风险表](risk_attribution.csv)一致：W1/W2 的 OAC/G0 中位分别为 1.177/1.190，触及 2 倍帽的对象为 8/512、11/511；在相同 K=52 下，OAC 与 G0 的排名交集为 45/40。这说明评分确实产生非统一建议，**不**说明建议对应干净重建收益。
- 两窗污染影子各影响 68/66 个探针，但其中 `A<1` 为 0/0。独立重算风险表：W1 的 512 个合格探针仅 11 个 `A<1`，其中 10 个 `G0=0`，11 个均未过三相机门；W2 的 511 个合格探针没有 `A<1`。所以现有 D 覆盖没有检验低证据对象的风险优势，也没有检验支持门对受污染对象的保护优势。
- 由汇总数据重算，`Σ(c−A)/[Σ(c−A)+Σ(n−c)]` 为 W1 50.81%、W2 46.50%。`c−A` 是已有贡献的接受损失，`n−c` 是投影但无合成贡献；二者不可合称 Mask 稀释，更不能直接称为可恢复的静态信息量。取证中原 count/grad 与影子 `Σz/Σg` 对齐，只证明按定义记录，不验证该定义的决策目标。

## 有条件的数学结论及边界

1. 对支持门通过且 `n>0、A>0` 的对象，未触帽的定义可化为 `G=(S+κG0)/(A+κ)=G0(n+κ)/(A+κ)`，其中 `S=Σg、G0=S/n、A=Σu、κ=4`。若固定 `u`、投影数与门状态，将全部 `g` 乘正数 `t`，连同以 `2G0` 为上限的帽及回退分支，输出也乘 `t`。因此它是同批统计的收缩重标度；`κG0` 不是独立先验，2 倍帽也不是任意梯度污染的绝对影响上界。`A≤n` 的解释仅在理想 `u∈[0,1]` 下成立；现有未裁剪浮点 `u` 有约 `10⁻⁷` 级越界，不影响上述代数恒等式。
2. 仅在**固定模型、IID、可积且 `g=u h、E[u]>0`** 的有利假设下，`Σg/Σu → E[h]+Cov(u,h)/E[u]`。零协方差或其他识别条件未建立。反例 `u∈{0,1}` 各半、`u=1` 时 `h=1`，而 `u=0` 时 `h=0` 或 `100`：两种世界的 `(u,g)` 完全同分布，`E[h]` 却为 0.5 或 50.5。它证明**仅凭这些观测**不可识别，不排除附加静态几何证据提供识别；真实训练参数变化也不满足该 IID 前提。这里的 `u=bM/b` 是 footprint 接受贡献比，并非观察概率或静态正确概率。
3. 固定局部方向 `φ≠0`、允许无约束标量 `a` 时，`L(a)=½‖r−aφ‖²` 的最优下降为 `(rᵀφ)²/(2‖φ‖²)`。`r=(1,1)` 与 `(1,−1)` 在 `φ=(1,1)` 下具有相同逐项绝对残差，却分别下降 1 与 0；即便约束 `a≥0`，这两个数仍成立。此反例只否定“非负幅度摘要足以唯一决定指定方向收益”的普遍说法，不是两套完整 3DGS 记录相同的构造；若旧参数可继续优化，还必须比较同等优化机会后的增量。
4. 有限图域上固定 Parent/候选渲染 `r,s∈[0,1]³`、观测 `Y`，允许**至多** `k` 个 RGB 像素任意替换时，令 `d_p=‖r_p−Y_p‖₁−‖s_p−Y_p‖₁`、`h_p=‖r_p−s_p‖₁`、`q_p=d_p+h_p≥0`。每像素内层最小值 `−h_p` 在 `Y*_p=r_p` 达到，故最坏平均损失改善恰为 `[Σd−TopSum_k(q)]/P`；加成本时再减 `λΔC`。这是固定渲染、逐像素可自由替换、L1、已知污染预算下的**精确初等基准**，不是实际 RU 污染模型或真实训练收益定理。若 `k≥|{p:r_p≠s_p}|` 且 `λΔC≥0`，下界恰为 `−Σh/P−λΔC≤0`，不能保证正收益。若近似渲染满足逐像素 `‖r−r̂‖₁+‖s−ŝ‖₁≤e_p`，最坏值误差至多 `Σe_p/P`；真实 alpha 遮挡下便宜且紧的 `e_p` **未建立**。独立 CPU 核对了 324 组小型子集枚举，最大数值误差 `1.78×10⁻¹⁵`；证明依据仍是前述逐像素不等式。
5. 对同一像素的两个完全重合子体，若父 alpha 为 `a`、子体各为 `a/2`，联合 alpha 为 `1−(1−a/2)²=a−a²/4`，并非 `a`（例如 `a=0.6` 时为 0.51）。这只警示“各半 opacity”不自动保持真实合成不变；不推翻特定论文在其局部模型下的结论。

## 决策信息缺口与已有工作

现有 `z`（投影条件）、`g`（屏幕 AbsGrad 幅度）、`b`/`bM`（合成/被接纳的贡献积分）、`m`（有贡献像素数）及相机 ID，没有定义一次**具体**拓扑动作的类型、子代几何/颜色/opacity、成本和与 Parent 对等的后续优化；也没有该动作的两套渲染、带符号像素残差与候选方向/Jacobian、真实干净目标 `Y*` 或可信污染集合及其覆盖保证。因此从缓存可计算评分与机会缺口，但不能识别动作相对于静态风险的收益、真实干净 top-K 或最优门限。多相机 ID 不等于独立且几何充分的静态约束。

原文核对的继承边界：[ReAct-GS](https://arxiv.org/html/2510.19653v1) 已研究梯度稀释、合成重要性加权及 primitive 重激活；[SteepGS](https://arxiv.org/html/2505.05587v1) 已给出分裂矩阵、二阶局部损失分析、最小特征方向与点数控制；[HarmoGS](https://arxiv.org/html/2605.13073v1) 已处理跨视图梯度冲突，并将其用于增密/剪枝。因此仅更换贡献权重、Hessian/特征值评分或增加视图冲突门，均不能直接宣称本项目原创。上述近邻核查不等于穷尽文献，也不能把其论文报告的效果移植为本项目结果。

**未建立：**真实 `Y*` 属于哪一个可信且非空的结构化不确定集合；现有观测是否足以排除瞬态污染与静态几何的不可区分解释；候选操作能否得到非空、可计算且足够紧的干净风险下界；该构想相对近邻工作的论文级新意；任何 30k 质量、FPS 或跨场景收益。有限像素闭式只是审题基准，不是新的已验证方法。当前仅保留“能否判断明确拓扑操作降低静态风险、何时不能判断”为待方案侧定义的研究问题；不命名新评分、不实施 P05，等待下一包决定。
