## Clean 基线

B1 相对 B0 的两场景平均 PSNR 为 `+0.100515 dB`，LPIPS 为 `-0.011589`，
Gaussian 比例为 0.707923，训练时间比例为 0.873220。因此 B1 满足预设条件，
被选为：

```text
efficiency-strong baseline
```

## A1 门禁

A1 相对 B1 的两场景平均变化为：

```text
PSNR  = -0.172801 dB
SSIM  = +0.000063
LPIPS = +0.000236
```

逐场景 PSNR：

```text
garden A1-B1 = +0.104086 dB
room   A1-B1 = -0.449688 dB
```

因此同时触发两个预设失败条件：

1. 两场景平均 PSNR 下降超过 0.15 dB；
2. room 单场景 PSNR 下降超过 0.30 dB。

FPS 门禁通过：A1/B1 为 garden 1.0163、room 1.0520。A1 也使用更少 Gaussian
和 VRAM，但效率优势不能替代 clean 质量硬门。

逐图结果进一步显示，garden 仅 8/24 张、room 仅 9/39 张的 A1 PSNR 高于 B1。
garden 的正平均值受到少数大幅改善视图影响；room 最差测试图的 A1-B1 PSNR
达到 `-4.53 dB`。

## 视觉复核

对 garden 和 room 各取首、中、末三个测试视图，并对 B0/B1/A1 共 18 张评测
画布进行同序复核。抽取视图中三种方法整体结构相近，没有观察到足以独立判定
“灾难性纹理破坏”的现象；部分细纹理、遮挡边界和高频区域存在细微差别。

视觉抽样不能推翻逐图全测试集上的硬性数值失败，尤其不能覆盖 room 的
`-0.449688 dB` 场景级下降。因此最终 clean 判定保持 `CLEAN_FAIL`。
